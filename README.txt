Skillhone Academy website

This is a self-contained static website. It contains Home, About, Programs, Experience, Insights and Contact pages, plus the supplied logo and Mahesh Krishnan's portrait.

To publish, upload the contents of this folder, including the assets folder, to the website host's public web root.

The training requirement form prepares an email addressed to mahesh@skillhone.in. Visitors review and send it in their own email app; the site does not store or transmit submissions. Connect an approved hosted form service if direct web form processing is required.
